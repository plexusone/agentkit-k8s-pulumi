## [v0.1.0] - 2026-07-13

### Highlights

- Initial release with Kubernetes deployment provider for cloud-agnostic container deployments

### Added

- Kubernetes `deploy.Provider` implementation with Deploy, Status, Destroy, and Close methods (`deploy/providers/kubernetes/provider.go`)
- K8s-specific configuration: namespace, replicas, service type, ingress, probes, tolerations, node selectors (`deploy/providers/kubernetes/config.go`)
- Pulumi automation API wrapper for programmatic stack management (`deploy/pulumi/stack.go`)
- Auto-registration with AgentKit provider registry at priority 50 (`deploy/providers/kubernetes/init.go`)
- Deployment resource creation with container spec, environment variables, and resource limits
- Service resource creation with ClusterIP, NodePort, or LoadBalancer types
- Optional Ingress resource with TLS support and configurable ingress class
- Liveness and readiness probe configuration from health check settings
- Pod annotations, labels, tolerations, and node selector support
- Image pull secrets for private registry authentication
- Service account configuration for RBAC
